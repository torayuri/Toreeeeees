# Toreeeeees ✏️

**スマホが、トレース台になる。**

画像を読み込んでサイズと位置を合わせたら「固定」。
あとはスマホの上に紙をのせて、透けた線をなぞるだけ。固定中は画面に触れても絵は動きません。

## できること

- **画像の読み込み** — タップで選択 / ドラッグ&ドロップ / 貼り付け（Ctrl+V）
- **サイズ調整** — ピンチで拡大・縮小、2本指で回転（0°/90°付近で吸着）、ドラッグで移動、スライダーで微調整
- **実寸指定** — カードで画面を校正すると、幅・高さを **mm** で指定可能
- **ワンタップ整列** — 全体表示 / 横幅に合わせる / 90°回転 / 左右・上下反転
- **見え方** — 白黒・ネガ反転・線をくっきり・コントラスト・明るさ・うすさ・背景色
- **ガイド** — グリッド（校正済みなら 10mm / 5mm）・中心線
- **ロック** — タッチ・ピンチ・スクロールを全部無効化。全画面化・画面スリープ防止・画面回転の固定（対応端末のみ）
  - 解除は四隅の鍵ボタンを **長押し（1.2秒）**。位置は設定で変更可
- **前回のつづき** — 画像と位置は端末内（IndexedDB）に保存され、次回すぐ再開
- **オフライン対応 / ホーム画面に追加** — PWA。iPhoneは「共有 → ホーム画面に追加」で全画面表示になります

画像はすべて端末内で処理され、外部には送信されません。

## 使うときのコツ

- 画面の明るさは **最大** に。背景「白」がいちばん透けます
- 紙が画面に触れても反応しないよう、必ず **固定してから** 紙をのせてください
- 自動ロック（スリープ）は固定中は防止されますが、非対応ブラウザでは端末の設定で「なし」にしておくと安心です

## GitHub Pages で公開する

1. このブランチを `main` にマージ
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に
3. `main` に push されると `.github/workflows/pages.yml` が自動でデプロイ
   → `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

ビルド不要の素の HTML / CSS / JS なので、ローカルでは `python3 -m http.server` などで確認できます。

## PC のショートカット

| キー | 動作 |
| --- | --- |
| ホイール | 拡大・縮小 |
| Shift + ホイール | 回転 |
| 矢印キー | 移動（Shift で大きく） |
| `+` / `-` | 拡大・縮小 |
| `F` | 全体表示 |
| `L` | 固定 |
